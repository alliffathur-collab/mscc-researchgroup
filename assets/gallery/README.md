# Media Gallery Assets

This folder contains images for the Media Gallery section.

## Structure

- **photo1.jpg - photo9.jpg**: Photos for the photo gallery slideshow (3 photos per slide, 3 slides total)
- **paper1-preview.jpg - paper5-preview.jpg**: Preview images for featured publications (recommended: first page of papers)

## Image Specifications

### Photos
- **Recommended dimensions**: 1200x900px (4:3 aspect ratio)
- **Format**: JPG or PNG
- **File size**: Keep under 500KB for optimal loading

### Paper Previews
- **Recommended dimensions**: 800x1100px (3:4 aspect ratio, similar to paper page)
- **Format**: JPG or PNG
- **File size**: Keep under 300KB
- **Content**: Screenshot or export of first page from journal/Elsevier showing title, authors, abstract

## Adding Your Images

1. Replace placeholder image names in `index.html` with your actual image filenames
2. Update alt text descriptions for accessibility
3. For paper previews, update the publication links in the HTML to point to actual DOI/journal URLs

## Tips

- Use descriptive alt text for all images for accessibility
- Optimize images before uploading (use tools like TinyPNG, ImageOptim)
- Keep consistent aspect ratios for better gallery appearance
- For paper previews, you can export PDF first pages as images using Adobe Acrobat or online tools
